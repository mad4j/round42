# Round 42

Versione browser in JavaScript ispirata allo sparatutto spaziale DOS del 1986.

## Come giocare

Apri `index.html` in un browser moderno. Non servono installazione o dipendenze.

- **← / →** oppure **A / D**: muovi la navicella
- **Spazio**: fuoco automatico
- **X**: laser (si ricarica completando un’ondata)
- **P** oppure **Esc**: pausa

Su schermi touch sono disponibili i pulsanti sotto il campo di gioco. Completa tutte
le 42 ondate e cerca di battere il tuo record.
